## 单元格含义

| 列                                | 取值                                                                                                                                                                                                                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Copy（server_copy 同存储）        | 同步返回（驱动调用返回即结束，不代表云端后台一定完成）/ 后台受理，不等待完成 / 未实现→OpenList传输任务 / 不支持（只读存储）/ 委托底层 / 空实现 / 随配置变化 / 完成时机未知；“重名”为目标已有同名对象时的行为：覆盖 / 报错 / 自动改名 / 允许重复 / 未知。只影响选择 server_copy 的 Job      |
| Put（relay 写入；目标已有同名时） | 原生覆盖 / OpenList先改名旧对象（NoOverwriteUpload，非崩溃安全）/ 自动改名 / 允许重复 / 驱动模拟覆盖 / 不可写 / 未知。relay 经 OpenList 分片接口写入，底层同为驱动 Put；本服务总是先删除旧文件再以 Overwrite:false 上传，此列只说明竞态或缓存失真时的底层行为。“不可写”的驱动不能作 Target |
