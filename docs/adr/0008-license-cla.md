# ADR 0008：AGPL-3.0-only，不设CLA

- 状态：accepted
- 日期：2026-10-19（2026-10-21修订：确定SPDX并取消CLA）
- 决策者：项目维护者

## 背景

项目开源，需要在发布阶段明确分发与贡献规则。

## 决策

采用AGPL-3.0-only（package.json的license字段同步），仓库根目录附LICENSE全文。不设CLA：贡献按同一许可证授权（inbound=outbound）。

## 考虑的替代方案

- AGPL-3.0-or-later：被维护者否决，许可条款固定为第3版。
- AGPL-3.0+CLA：原决策，M8时取消。维护者作为自身代码的版权人本就保留商用与再许可的权利；CLA只在需要再许可外部贡献时有意义，且没有律师起草与维护签署流程。今后确有需要可再引入，届时之前合并的贡献仍只按AGPL授权。

## 后果

- 收益：许可证义务覆盖以网络服务形式提供的修改版（AGPL-3.0第13条）。
- 代价：运营修改版并向用户提供网络服务的一方须提供对应源码；部分组织限制使用AGPL软件。
- 外部贡献的版权归贡献者，维护者只能按AGPL-3.0-only使用；以其他许可证分发包含这些贡献的版本需要贡献者另行授权。
