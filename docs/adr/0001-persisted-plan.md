# ADR 0001：持久化三阶段计划

- 状态：accepted
- 日期：2026-10-19
- 决策者：项目维护者

## 背景

dry-run、统一删除预算、批量操作记录和崩溃可见性需要完整计划边界。

## 决策

采用Scan+Plan→Safety→Execute；SQLite分批存计划，planned前不写远端；不保存跨运行文件索引。

## 考虑的替代方案

边扫描边复制可更早传输，但无法先给出全量删除预算和完整预览，因此不作为基线。

## 后果

- 收益：执行前即可得到完整计划、统一的删除预算和dry-run预览；崩溃后能从持久化计划看出已执行与未执行的部分。
- 代价：增加扫描启动延迟和数据库写入。
- 已接受风险：计划在执行时可能已过期，因此执行前复查相关前提；扫描中途崩溃不执行部分计划。
