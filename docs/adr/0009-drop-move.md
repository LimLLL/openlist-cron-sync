# ADR 0009：MVP移除源端move

- 状态：accepted
- 日期：2026-10-19
- 决策者：项目维护者

## 背景

多目标交付确认、异步copy、task_group删除弱点和崩溃窗口使安全源删除远超MVP范围。

## 决策

源文件内容与目录结构永不修改；删除源move模式、delete_source和removeEmptySourceDirs。本服务不调用任何move接口。

## 考虑的替代方案

先拷多数目标再对最后目标move、同大小即删源等方案均不进入MVP。

## 后果

- 收益：源端没有因本服务导致的丢失风险；同步语义只涉及目标。
- 代价：需要“同步后清空源”的用户只能在本服务之外处理源端。
- 不提供的保证：未来若恢复move，必须重新讨论交付确认、源变化和所有目标的协调，不能直接复用当前成功语义。
