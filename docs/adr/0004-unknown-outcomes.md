用途：记录未知操作结果只作为历史、后续运行独立规划的决策与风险。

范围：单进程同步服务；保留正在运行的 Run 之间的路径互斥及已知远程任务的并发额度。

# ADR 0004：未知结果保留历史，后续运行独立规划

- 状态：accepted
- 日期：2026-10-28
- 决策者：项目维护者

## 背景

远端操作可能已经生效却丢失响应，也可能在本地 Run 结束后继续执行。生产故障中，后续 Run 已观察到 596 个目标路径不存在，却因历史未知结果跳过全部路径。以时间推测旧请求结束的策略延迟了副本恢复，也不能证明远程副作用已经停止。

## 决策

1. unknown 是不可改写的 Operation 终态，同一 Run 不自动重试。它阻止 Run 成功；按已有聚合规则为 partial 或 failed，取消和重启仍优先为 cancelled 或 interrupted。
2. 后续 Run 使用自己的配置快照和扫描结果：缺失则 create，文件大小不同则删除旧文件、确认名称消失后 create，同名同类型同大小则 unchanged，mirror extras 仍执行普通删除保护。历史 unknown 不参与路径准入，不产生额外 refresh 义务。
3. 不提供历史结果的释放或放弃管理动作，不保存观察解决记录。普通扫描遵守端点 refresh 设置；删除前提、删除确认和操作错误后的有界观察仍按各自规则强制 refresh=true。
4. 保留活动 Run 的 source 读取与 target 写入路径占用，包括祖先、后代和已知账号别名。保留同一 Run 的操作依赖、逻辑动作认领、源准备、删除预算、挂载保护和 overwrite=false。
5. server_copy 允许与前轮未结束的远程任务重复提交，不增加按路径检查远程任务的阻断规则。已知且未结束的历史任务仍消耗稳定 Target 的 concurrentFiles 额度；容量耗尽时新提交仍需等待。
6. 维护仅更新原操作的远程任务状态。终态回到非终态只记录日志，不新增 REMOTE_TASK_CHANGED 操作；任务再次终态后才删除远程任务记录。不可观察的遗留任务使用现有有界 housekeeping 策略，不因历史 unknown 无限延长责任。
7. 历史 unknown 不阻止实例身份修改或历史保留期删除。活动 Run 和仍待删除的远程任务记录继续承担独立责任。

## 后果与边界

旧写入、删除或中止后的删除可能迟到生效，覆盖或删除较新的目标。abort 成功、会话消失或过期都不证明驱动和云端已经停止。本服务只读 source，但无法完整识别跨地址、挂载或符号链接的底层别名。

后续 Run 只修复其扫描能识别且保护规则允许处理的差异，不承诺最终自动修复：

- 同大小的错误内容或源修改仍视为 unchanged。
- 文件与目录冲突记 TYPE_CONFLICT 并保护，不自动替换类型。
- 缓存视图可能继续隐藏变化；没有后续成功 Run 就没有修复。
- incremental 保留目标 extras，包括迟到创建但已不在源中的文件；mirror 仍受过滤、完整性和删除预算约束。
- 目标被另一个 Job 当作源时，迟到变化可能传播到下游副本。
- OneDrive 的 mkdir 冲突可能生成改名空目录；incremental 可能保留，mirror 也仅在 syncEmptyDirs=true 且删除保护允许时删除。

这些风险由维护者接受，不增加特殊清理路径、内容哈希、持久锁或新的路径阻断机制。

## 数据升级

迁移删除旧路径阻断、释放、观察解决及因果引用字段，并仅从 Run 冻结快照删除退役的期限设置。旧状态、错误码、时间、尝试和传输事实保留；旧 REMOTE_TASK_CHANGED 行当时仍可读、不计入执行统计，后在 [ADR 0010](0010-operation-attempts.md) 的迁移中删除。释放/放弃原因和观察解决来源永久丢失，降级需恢复升级前数据库备份。

OpenList 可为 failed_retriable 会话返回相同 upload ID，因此 upload ID 不再要求在全部历史中唯一。每次尝试的 ID/attempt 一致性检查保留；失败会话记录失败并尝试 abort，下一尝试再 init，不接管旧会话续传。
