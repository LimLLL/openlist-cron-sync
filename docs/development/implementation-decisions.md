用途：登记在已接受的产品规则内、为实现可执行性补全的具体选择。

范围：只补全已接受的产品规则（见[需求](../design/requirements.md)与[决策记录](../README.md#决策记录)），不改变这些规则；法律文本待发布阶段定稿。
