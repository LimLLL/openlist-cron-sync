## Post-MVP

| 项目                         | 推迟原因及重启讨论条件                                                                                                                                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 源端move                     | 必须先定义所有目标交付确认、后台copy完成、源运行中变化和失联恢复；同大小不证明内容相同，task_group.verifyAndRemove依赖存在性且清理失败可能只日志；不能最后目标move提前删源 |
| 常规复制后校验               | MVP明确不做；未来区分名称大小、hash与读取验证，需讨论权限、缓存和云API成本                                                                                                 |

| 跨重启续传与共享下载         | 当前本服务重启后不续传旧multipart session，多目标时各自下载；跨重启续传需持久化块索引与session，共享下载需分组准入与引用计数                                               |
| SSE进度                      | 当前轮询够用；未来考虑连接生命周期、断线重放及鉴权                                                                                                                         |
| per-target filters           | 当前Job统一规则，避免各目标管理范围含义分裂                                                                                                                                |
| 通知适配器                   | Telegram/Bark/ServerChan等在Webhook稳定后按需求加入                                                                                                                        |
| 更强通知可靠性               | 当前best-effort；持久outbox/跨重启补投仅在明确要求后设计                                                                                                                   |
| 非空目录整批删除优化         | 当前逐文件和确认空目录，避免过滤绕过和目录任务子树句柄缺失                                                                                                                 |
| 完整Unicode/文件系统命名适配 | 简单fold只发现已知冲突，不能保证所有目标等价关系                                                                                                                           |
| 在线主密钥轮换工具           | 当前只定义维护前提，未提供在线轮换API或迁移工具                                                                                                                            |

双向同步和多副本部署明确非当前目标，不默认承诺某个未来版本实现。
